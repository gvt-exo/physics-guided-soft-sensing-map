# Manuscript figures

`paper/main.tex` is the manuscript source of truth. This directory intentionally contains only the four vector PDFs referenced by the current manuscript:

- `fig_extended_validation_timeline.pdf` — full process/laboratory timeline and maintenance gap;
- `soft_sensor_architecture.pdf` — physics-guided soft-sensor and validation workflow;
- `fig_extended_adaptation_comparison.pdf` — frozen-versus-adapted error comparison;
- `fig_extended_transfer_timeseries.pdf` — external-transfer predictions and residuals.

All labels are public, anonymized descriptions. PNG previews and legacy analysis figures are intentionally excluded from the release. The validation workflow exports vector PDF only.
